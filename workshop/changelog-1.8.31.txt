1.8.31 — co-op desync fix (Cursed Deck)

- Co-op: fixed a desync ("state divergence") at the start of a turn when a player held a curse in a Cursed Deck run. The game sometimes recompiles a patched method in the background and drops the mod's patch on one player's game for a moment; the curse's cost then read differently on the two games. The mod now restores every patch right before each game action and each co-op state check, instead of only over the next few frames.
