# Spoon Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Custom Run modifier "Spoon" / "Cuillère": max HP growth all run (Spoonful card, max HP relics, Feast rest
option, Fruit Juice at every merchant) and an extra one-room act whose boss, the Spoon, only 300+ max HP players fight.

**Architecture:** Pure numbers and decisions in `src/Core/SpoonRule.cs` (xUnit). Game glue in `src/Spoon/`. The Spoon
act is an appended `ActModel` like `Sts1EndingAct`; the Ending's act patches are generalized through a small
`IAppendedAct` interface so both acts share them. The act is inserted from the modifier's `AfterCombatVictory`, which
vanilla runs before it sets `WinTime` and saves (`CombatManager` ~line 999–1010), so the act 3 boss stops being final.

**Tech Stack:** C# .NET 9, Harmony, Godot 4.5.1 PCK, xUnit; `make build`, `make test` (Podman).

**Spec:** `docs/superpowers/specs/2026-11-14-spoon-design.md`

## Global Constraints

- Every text in `godot/SlaySpoon/localization/eng/` and `.../fra/`; repo text and comments in English.
- Standard and Daily stay vanilla: everything is gated on `SpoonSpoon.IsActive(run)`.
- Vanilla RNG streams never move: every random choice uses `new Rng(run.Rng.Seed, "SlaySpoon.Spoon.<purpose>")`.
- Never write the regular save; never commit decompiled code; Harmony helpers never named Prefix/Postfix/Transpiler/Finalizer/Prepare.
- Threshold 300 max HP; Spoonful 10 dmg / +3 max HP (upgrade +2 / +1), Retain, Innate, no Exhaust, Eternal;
  Feast +5 max HP; gift −5 / +5, cost 1; Spoon ≈1500 HP per fighter; Bouchée 30 dmg + 10 max HP eaten (heals
  the Spoon by the max HP eaten); Ladle Smash 50 dmg; +3 Strength per turn;
  `damage = base × (300 × players) / teamMaxHp`, floor, min 1.
- Nothing is given back after the Spoon fight. Losing it is a defeat.
- Commits on branch `two-modes`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No push.
- Version 1.3.0 in `mod/SlaySpoon.json` and `src/ModEntry.cs` (Task 6).

## Review Focus

- A10 (two act 3 bosses): the Spoon is inserted only after the **second** boss; the first boss still gives no rewards.
- Act 4 run with all keys, Ending already appended at index 3: the Spoon lands at index 3 and the Ending at 4; the
  Ending's load/next-act guards (`EnsureEndingAct`) must neither append a second Ending nor skip it when the Spoon is
  present (Task 4 `EndingRouteRule` tests), and a save reloaded on the act 3 boss reward screen keeps both acts.
- Co-op where only one player is 300+: the Spoon targets only that player, the supporter takes 0 and deals 0,
  and the fight ends in defeat when the fighter dies even though the supporter lives.
- Spoon's intent numbers equal the damage actually dealt (scaling through `ModifyDamageMultiplicative`, which
  intents read too).
- Merchant that already rolled Fruit Juice: no second one, and no extra draw on a vanilla Rng.

### Task 1: SpoonRule (pure logic)

**Files:**
- Create: `src/Core/SpoonRule.cs`
- Test: `tests/SpoonRuleTests.cs`

**Interfaces:**
- Produces (all `public static` on `SlaySpoon.Core.SpoonRule`):
  - `const int Threshold = 300, FeastMaxHp = 5, GiftMaxHp = 5, HpPerFighter = 1500, BoucheeDamage = 30, BoucheeMaxHp = 10, LadleDamage = 50, StrengthPerTurn = 3`
  - `bool ShouldInsert(bool spoonRun, bool vanillaActIndexIsLast3, bool atLastBoss, IReadOnlyList<int> maxHps, bool alreadyInserted)` — true when the run is a Spoon run, the current act is act index 2, the fight was the act's last boss (second boss at A10), someone has ≥ 300 and no Spoon act exists yet.
  - `int InsertIndex(int actCount, bool endingPresent)` — 3 in both cases (asserts the act list is `[3 vanilla]` or `[3 vanilla, Ending]`); returns -1 for any other shape.
  - `IReadOnlyList<int> Fighters(IReadOnlyList<int> maxHps)` — indexes with max HP ≥ 300.
  - `int ScaledDamage(int baseDamage, int players, int teamMaxHp)` — `floor(base × 300 × players / teamMaxHp)`, min 1, base ≤ 0 → 0, teamMaxHp ≤ 0 → base.
  - `decimal DamageMultiplier(int players, int teamMaxHp)` — `300 × players / teamMaxHp` (used by the hook; `ScaledDamage` is its rounded form for tests and logs).
  - `int BossHp(int fighters, int players)` — `ceil(1500 × fighters / players)` (vanilla then multiplies by players × act-3 boss factor in co-op, giving ≈1500 × fighters × 1.3; solo 1500).
  - `enum SpoonMove { Bouchee, Ladle }` and `SpoonMove Move(int turn)` — Bouchée, Bouchée, Ladle, repeating (turn zero-based).
  - `RelicRarity`-free table: `IReadOnlyList<(string Entry, string Deque)> ExtraRelics` = Event/Ancient relics and the deque they join: `LOOMING_FRUIT`→Rare, `BIG_MUSHROOM`→Rare, `NUTRITIOUS_OYSTER`→Uncommon, `STONE_HUMIDIFIER`→Uncommon, `DARKSTONE_PERIAPT`→Uncommon, `CHOSEN_CHEESE`→Uncommon, `FAKE_MANGO`→Common. (Mango, Pear, Strawberry, Dragon Fruit, Lee's Waffle are already in the ordinary pools.)
  - `int JuiceSlot(int potionCount, bool hasJuice, int roll)` — -1 when `hasJuice` or `potionCount == 0`, else `roll % potionCount`.
